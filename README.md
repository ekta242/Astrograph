# Astrograph 🌌

An AI-powered career guidance app that maps your professional 
journey as a constellation in the sky.

## What it does
- Analyzes your resume or career notes using Gemini AI
- Assigns you a unique "Professional Constellation" based on 
  your career archetype
- Generates a personalized psychometric quiz to map your 
  professional strengths
- Creates a 5-step career ascension roadmap tailored to your profile
- Visualizes your career trajectory as an interactive star map

## Tech Stack
- React + TypeScript
- Vite
- Google Gemini API (structured JSON responses)
- Custom constellation visualization

## How to run
1. Clone the repo
2. Run `npm install`
3. Add your Gemini API key to `.env.local` as `GEMINI_API_KEY`
4. Run `npm run dev`
